12. String methods:
		* Upper Case: Converts to uppper case:[String.upper()]:	String
				EG: Input: a="shubham"
					   print(a.upper())
				    Output: SHUBHAM

		* Lower Case: Converts to lower case:[String.lower()]:	String
				EG: Input: a="SHUBHAM"
					   print(a.lower())
				    Output: shubham

		* Swap case: Converts upper to lower case and lower to upper case:[String.swapcase()]:	String
				EG: Input: a="ShubhaM"
					   print(a.swapcase())
				    Output: sHUBHAm

		* Strip: Strips off the characters in the string from the end:[String.rstrip("ANY CHARACTER")]:	String
				EG: Input: a="SHUBHAM!!!"
					   print(a.rstrip("!"))
				    Output: SHUBHAM

		* Replace: Converts all the words into the given words:[STRING.replace("Anything in the STRING","Anything we want")]:	String
				EG: Input: a="Shubham"
					   print(a.replace("Sh","A"))
				    Output: Aubham

		* Split: Converts the given sentence into multiple elements of a list by separating it by the given character:[String.split("Any separator")]:	String List
				EG: Input: a="Hello Shubham"
					   print(a.split(" "))
				    Output:['Hello','Shubham']

		* Capitalize: Converts the first character of the sentence to upper case and the rest to lower case:[String.capitalize()]:	String
				EG: Input: a="shubham"
					   print(a.capitalize())
				    Output: Shubham
		
		* Ttitle: Converts the first character of each word of the sentence to upper case and the rest to lower case:[String.title()]:	String
				EG: Input: a="shubham is here"
					   print(a.capitalize())
				    Output: Shubham Is Here

		* Center: Centrelizes the words of a string:[String.center()]:	String
				EG: Input: a="SHUBHAM"
					   print(a.center())
				    Output: 	     SHUBHAM

		* Count: Calculates the number of occurances of a word or letter in the string:[String.count("")]:   int
				EG: Input: a="Hello world Hello Life!"
					   print(a.count("Hello"))
				    Output: 2

		* End: Checks if the string ends with a given word or not:[String.endswith(),index position start,end]:   boolean
				EG: Input: a="Shubham"
					   print(a.endswith("hu",1,2))
				    Output: true

		* Start: Checks if the string starts with a given word or not:[String.startswith(),index position start,end]:   boolean
				EG: Input: a="Shubham"
					   print(a.startswith("S"))
				    Output: true

		* Find: Finds the index number of the first occurances of the word or letter in the string and returns -1 if the word or letter is not there:[String.find("")]:	int
				EG: Input: a="Shubham"
					   print(a.find(u))
				    Output: 2

		* Index: Finds the index number of the first occurances of the word or letter in the string and terminates if not found:[String.index("")]:	int
				EG: Input: a="Shubham"
					   print(a.find(v))
				    Output: Error

		* Alnum: Returns true if only a-z and 0-9 irrespective of their case, is present and no other panctuations is present:[String.isalnum()]:	boolean
				EG: Input: a="Shubham002"
					   print(a.isalnum())
				    Output: true
					
				    Input: a="Shubham0.20"
					   print(a.isalnum())
				    Output: false

		* Alpha: Returns true if only a-z irrespective of their case, is present and no other panctuations is present:[String.isalpha()]:	boolean
				EG: Input: a="Shubham"
					   print(a.isalpha())
				    Output: true
					
				    Input: a="Shubham.02"
					   print(a.isalpha())
				    Output: false

		* IsLower: Returns true if all the charaacters in the string are in lower case:[String.islower()]:	boolean
				EG: Input: a="Shubham"
					   print(a.islower())
				    Output: false
					
				    Input: a="shubham."
					   print(a.islower())
				    Output: true

		* IsUpper: Returns true if all the charaacters in the string are in upper case:[String.isupper()]:	boolean
				EG: Input: a="Shubham"
					   print(a.isupper())
				    Output: false
					
				    Input: a="SHUBHAM."
					   print(a.isupper())
				    Output: true

		* IsTitle: Returns true if the first letter of all the words of a string is in caps:[String.istitle()]:	boolean
				EG: Input: a="Hello Shubham"
					   print(a.istitle())
				    Output: true
					
				    Input: a="Hello shubham."
					   print(a.istitle())
				    Output: false
